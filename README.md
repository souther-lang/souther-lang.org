# Souther

Source for [souther-lang.org](https://souther-lang.org), built with Astro and Starlight.

## Development

```sh
npm install
npm run dev
```

## Deployment

Pushes to `main` are deployed to GitHub Pages by GitHub Actions. Configure the
repository’s Pages source as **GitHub Actions** before the first deployment.

The production domain is configured in `public/CNAME`. Set up and verify the
domain in GitHub Pages, then point its DNS records at GitHub Pages.
